# COMP211-Checkoff3

My topic is simple encryption using XOR. Every letter or number have a binary representation in ASCII, by XOR this number with a secret key can protect the message from being decrypted by other people who do not have access to the key. 

I explored simple examples of encryptions using XOR. Also, I explore the possibilities of how an encrypted message can be decrypted using a wrong key but still produce a redable message. I also explore how to make an XOR encryption secure. 

The most interesting discoveries is that a wrong key can decrypt to a wrong message and XOR encryption is popular in nowadays encryption methods. It's interesting to know that the XOR encryption is actually very secure even it is very simple to implement.
